📁 Portfólio Espacial - Lucas da Silva
Repositório do portfólio pessoal de Lucas da Silva, desenvolvido com o objetivo de apresentar seus projetos, experiências e habilidades técnicas de forma moderna, responsiva e interativa, com um tema espacial único.

📌 Sobre o Projeto
Este projeto consiste em uma landing page/portfólio responsiva, criada para destacar:

🎯 Projetos Realizados: Apresentação de trabalhos com descrições, tecnologias aplicadas e links para visualização ou repositórios.
👨‍💻 Sobre Mim: Um resumo profissional com trajetória, interesses e principais competências.
⚙️ Habilidades Técnicas: Tecnologias, linguagens e frameworks dominados, com visual interativo e ícones representativos.
📬 Contato: Links para redes sociais, e-mail e GitHub para facilitar o networking profissional.
🛠️ Tecnologias Utilizadas
Next.js: Framework React para renderização otimizada e suporte ao diretório app.
React: Biblioteca para construção de interfaces dinâmicas e reutilizáveis.
Tailwind CSS: Framework CSS para estilização rápida e responsiva.
Framer Motion: Animações suaves e interativas.
React Icons: Ícones representativos para tecnologias e habilidades.
Vercel: Hospedagem e deploy contínuo.
Git e GitHub: Controle de versão e colaboração.
